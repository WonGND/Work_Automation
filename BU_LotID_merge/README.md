# BU LotID 정리 도구

LotID별 최신 이미지 폴더를 선별하고 측정 데이터와 이미지를 정리해 엑셀 보고서를 만드는 Windows 업무 도구입니다.

## 실행

GUI의 표준 진입점은 다음과 같습니다.

```bash
python BU_organize_gui.py
```

GUI 없이 동일한 파이프라인을 실행하려면 다음 파일을 실행합니다.

```bash
python bu_pipeline.py
```

## 처리 순서

1. 입력 폴더 전체에서 이미지가 직접 들어 있는 LotID 폴더를 재귀 탐색하고, 같은 LotID는 생성·수정 시각이 가장 최신인 폴더를 선택합니다.
2. 선택한 폴더를 결과 merge 폴더에 병렬 복사하고, 선택 대상에 없는 이전 결과는 제거합니다.
3. `LMK6DataLog.csv`를 재귀 탐색해 LotID별 최신 판정, Black Uniformity(BU), White Uniformity(WU)를 읽습니다.
4. 이미지의 검은 배경을 병렬 크롭합니다.
5. **BU Image 분석** 체크박스를 켠 경우에만 BU 이미지의 색 분포와 weak point 를 계산합니다. 끄면 이 단계를 건너뜁니다.
6. 이미지와 측정값을 담은 `crop_report.xlsx`, 그리고 `merge_report.csv`를 저장합니다. 분석을 켰다면 그 결과도 같은 엑셀 파일에 함께 들어갑니다.

결과 폴더는 입력 폴더 옆에 `<입력명>_LotID_latest_v1`과 `<입력명>_LotID_latest_v1_cropped_v1` 이름으로 생성됩니다.

진행 상황은 단계 머리말(`[3/6] 측정 CSV 스캔`), 파일별 `... 파일 생성 완료` 문구, 전체 퍼센트가 함께 표시됩니다.

## BU Image 분석

제품별 BU 히트맵의 색 분포와 weak point 위치를 정리합니다. 결과는 별도 파일로 나누지 않고 `crop_report.xlsx` 한 곳에 모읍니다. 이미지와 수치를 오가며 볼 때 파일을 두 개 열지 않아도 됩니다.

`결과` 시트에는 기존 A~F 열 뒤로 `Weak 비율(%)`과 `Weak 집중 영역` 두 열이 붙습니다. 분석을 끄면 이 열은 만들지 않으므로 이전 양식 그대로입니다.

분석 전용 시트는 다섯 장입니다.

- `제품별_요약`: LotID별 평균 심각도, weak 비율, 가장 취약한 영역, 색 6종 비율
- `영역별_Weak`: LotID를 행, 9분할 영역을 열로 펼친 표. weak가 잡힌 칸에 붉은 배경이 들어갑니다
- `영역별_누적`: 여러 제품을 겹쳐 위치별 평균·최대 weak 비율과 검출 제품 수를 집계
- `판정_기준`: 아래 심각도 기준을 그대로 기록
- `색분포_맵`: BU 이미지를 48x27 격자로 줄여 셀 배경색으로 다시 그린 표. weak로 잡힌 칸은 굵은 테두리로 표시합니다

`색분포_맵`은 이미지를 그대로 넣는 대신 셀로 그립니다. 엑셀에서 특정 칸을 짚어보거나 옆에 수치를 붙여 비교할 수 있습니다. 제품이 아주 많으면 앞 200개까지만 그리고 시트 끝에 안내를 남깁니다.

### 색과 심각도

계측기 출력은 초록이 가장 양호하고 흰색이 가장 낮은 데이터입니다.

| 색 | 심각도 | 비고 |
| --- | --- | --- |
| 흰색 | 1.00 | 가장 낮은 데이터 |
| 노랑 | 0.80 | |
| 주황 | 0.60 | weak point 판정 하한 |
| 빨강 | 0.40 | |
| 청록 | 0.15 | 초록보다 낮음 |
| 초록 | 0.00 | 가장 양호 |

심각도 0.60 이상, 즉 주황·노랑·흰색을 weak point로 봅니다.

실측 53장으로 확인하면 BU 수치와 색 비율의 상관계수는 노랑 -0.740, 주황 -0.677, 빨강 -0.601로 모두 음의 상관입니다. 색이 나쁠수록 BU 수치가 낮다는 뜻입니다.

### 흰색을 두 번 거르는 이유

계측기는 패널 위에 흰 글자와 테두리를 얹습니다. 흰색 픽셀을 전부 최악값으로 보면 모든 패널의 상단이 weak point로 잘못 잡힙니다. 실측에서 흰색 픽셀의 세로 획 길이 중앙값은 2~3px이었고, 서로 다른 두 패널의 흰색 위치가 겹치는 비율(IoU)은 0.005였습니다.

그래서 두 단계를 거칩니다. 먼저 침식으로 얇은 획을 지우고, 남은 덩어리 주변이 노랑·주황인지 봅니다. 컬러맵이 연속이라면 최악값인 흰색 옆은 그다음으로 나쁜 노랑이어야 하기 때문입니다. 실측에서 불량 패널은 70.9%, 양품은 6.8%로 갈렸고, 기준값 40%를 넘는 쪽만 실제 데이터로 인정합니다.

제품 영역은 히트맵 본체를 찾아 안쪽으로 1.5%만 깎습니다. 고정 5% 마진을 쓰면 히트맵이 좌우로 90px씩 잘려서 쓰지 않습니다.

### 분석 해상도

계측기 원본은 4000px 급이라 그대로 훑으면 픽셀 연산이 네 배 비쌉니다. 폭이 1600px 이상이면 절반으로 줄여 분석합니다. 실측에서 1/2 축소는 weak 비율과 집중 영역, 흰색 판정이 모두 원본과 같게 나왔고 속도는 네 배 빨라졌습니다. 1/3 부터는 침식이 글자 획을 과하게 지워 흰색 판정이 뒤집히므로 쓰지 않습니다.

`bu_image_analysis.py`는 numpy와 Pillow만 사용합니다. `matplotlib`이나 `cv2`가 없어도 동작합니다.

## 설정과 로그

- `tovis_bu_data_settings.json`: GUI가 실행 위치에 생성하는 사용자별 설정 파일입니다. 경로와 테마를 저장하므로 Git 추적 대상에서 제외합니다.
- `TOVIS_BU_DATA_정리_log.txt`: GUI 실행 로그입니다. `*_log.txt` 규칙으로 Git 추적 대상에서 제외합니다.

## 독립 CLI

- `BU_LotID_merge_v1.py`: 측정 데이터와 엑셀 작업 없이 최신 LotID 폴더 취합과 `merge_report.csv` 생성만 수행합니다.
- `BU_black_bg_crop_to_excel_v1.py`: LotID 취합과 측정 데이터 결합 없이 지정 폴더의 이미지 크롭과 엑셀 생성을 수행합니다.
- `BU_organize_one_click_v033.py`: 48×27 BU grid, worst-point 및 시각화 분석 기능을 담은 고급 분석 도구입니다. 표준 파이프라인과 별개로 계속 사용합니다.
- `bu_weakpoint_view.py`: v033 전용 weak point 위치 분포 시각화 모듈입니다.
- `bu_image_analysis.py`: 표준 파이프라인이 쓰는 BU Image 색 분포·weak point 분석 모듈입니다.

## Weak Point 위치 분석 (v033, 참고용)

아래 내용은 v033 계열 전용입니다. v033은 컬러맵을 파랑=양호 → 빨강=불량으로 가정하는데, 실측으로 확인한 계측기 출력 순서는 초록=양호 → 청록 → 빨강 → 주황 → 노랑 → 흰색=최악입니다. 표준 파이프라인의 BU Image 분석은 v033 기준을 쓰지 않고 위 "BU Image 분석" 절의 기준을 따릅니다.

v033이 가정한 false-color 히트맵(파랑=양호 → 청록 → 초록 → 노랑 → 빨강=불량)에서 빨간 영역이 패널의 **어느 위치에** 몰려 있는지 확인하기 위한 기능입니다.

심각도는 색을 HSV 색상환 각도로 되돌려 계산합니다. 계측기 컬러맵 순서를 그대로 따르므로 파랑 0.0 → 청록 0.25 → 초록 0.5 → 노랑 0.75 → 빨강 1.0 으로 단조증가하며, 계측기가 얹은 흰색 글자나 회색 UI 같은 무채색은 후보에서 제외됩니다.

weak point 는 **노랑·주황·빨강 영역 전체**를 대상으로 합니다. 색상환에서 노랑과 연두가 갈리는 지점이 hue 70도이고 이를 심각도로 환산하면 0.708 이라, `WEAK_SEVERITY_MIN` 을 그 값으로 두었습니다. 기준을 바꾸려면 이 상수만 조정하면 됩니다.

`bu_grid_analysis.xlsx` 의 `요약` 시트에 **Weak Point 위치 분포** 이미지가 삽입됩니다. 결과 폴더가 지저분해지지 않도록 이 그림은 별도 PNG 파일로 남기지 않고 엑셀 안에만 넣습니다. 분석한 패널 전체를 누적해 위치별 weak 발생률과 평균 심각도를 나란히 보여주고, 반복해서 취약한 좌표 TOP5 를 캡션으로 적습니다. 여러 장에서 같은 자리가 반복되면 개별 패널 불량이 아니라 설비·공정 쪽 원인을 의심할 근거가 됩니다.

모듈을 직접 호출하면 패널 한 장에 대한 4분할 상세 도표도 만들 수 있습니다.

```python
from pathlib import Path
import bu_weakpoint_view as wv

analysis = wv.analyze_weak_points(Path("LOT001_BU_01.png"), grid_cols=48, grid_rows=27)
print(analysis.summary_text())
# weak 67셀 / 전체 1178셀 · 최다 집중 영역 좌상 (63셀, 해당영역의 50%)

wv.render_distribution_map(analysis, Path("dist.png"), source_image=Path("LOT001_BU_01.png"))
wv.render_aggregate_map([analysis], Path("aggregate.png"))
```

`render_distribution_map` 은 원본+weak 셀 윤곽, 심각도 그리드, 3×3 영역별 집중도, 행·열 프로파일을 한 장에 담습니다. `zone_distribution()` 은 좌상/중상/우상 … 형태의 9분할 집중도를 dict 로 돌려주므로 엑셀이나 로그에 그대로 쓸 수 있습니다.

`matplotlib` 이 필요하며, 한글 라벨은 Malgun Gothic → NanumGothic → Noto Sans CJK 순으로 탐색해 적용합니다.

`요약` 시트에는 LotID 행마다 `Weak 집중 영역` / `Weak 셀수` / `영역 점유율` 컬럼이 추가됩니다. 좌상·우상 같은 위치가 그림뿐 아니라 셀 값으로도 남아, 여러 LotID를 정렬·필터·피벗으로 한 번에 훑을 수 있습니다.
