# ECAD–MCAD registration (`pcbsim match`)

`pcbsim match` aligns a mechanical drawing (DXF, DWG, or STEP) to the fabricated board (Gerber X2/X3 + Excellon), checks that the two agree, and turns the mechanical items into thermal boundary conditions for `pcbsim run`.

Division of responsibility:

| information | source of truth |
| --- | --- |
| copper, pads, vias, drill holes, board outline, component placement | **Gerber / Excellon** (or a pick-and-place CSV) |
| heat sinks, chassis contacts, case / air gap, height limits, 3D bodies | **DXF / DWG / STEP** |

Formulas and references are in [`theory.md` §8](theory.md#8-ecadmcad-registration--pcbsimiogerberexcellondxfdwgsteppy-pcbsimregistration).

## Quick start

```bash
cd examples/mech
pcbsim match --gerber gerber --mech mech.dxf --map layers.yaml \
             --report report/match.html --json match.json
pcbsim run soc_with_mech.yaml            # uses match.json; stops if it is NG
pcbsim run soc_with_mech.yaml --force    # simulate anyway (warning printed)
```

`examples/mech/` is generated by `python -m tests.cad_fixtures examples/mech`. It contains KiCad-8-style Gerber X2/X3 and Excellon files and a FreeCAD-style DXF, drawn rotated by 30° in its own frame.

## Command line

```
pcbsim match [--gerber DIR] [--drill FILE ...] --mech FILE [--mech FILE ...]
             [--step FILE ...] [--pnp CSV] [--map layers.yaml]
             [--report out.html] [--json match.json] [-v]
```

* `--gerber` loads every Gerber file in the directory. Layers are identified by the X2 `.FileFunction` attribute, or by the KiCad/Protel file name when the attribute is missing. If no `--drill` is given, the `*.drl` / `*.xln` files in the same directory are used.
* `--mech` accepts `.dxf`, `.dwg` (converted first, see below), and `.step`/`.stp` (needs `pip install 'pcbsim[step]'`). Several files are merged.
* `--pnp` uses a centroid CSV (KiCad `*-pos.csv` or generic `Ref,PosX,PosY,Rot,Side[,Height]`) instead of the Gerber X3 component layer.
* `--report` writes a self-contained HTML report (overlay SVG, NG table, derived boundaries) and a JSON file next to it. `--json` alone writes only the JSON.
* Exit code 0 = PASS, 4 = NG items, 1 = invalid input. `pcbsim run` exits 5 when the linked match is NG and `--force` was not given.

## Layer map (`layers.yaml`)

Layer selectors are case-insensitive regular expressions matched against the full DXF layer name. Bare lengths are millimetres.

```yaml
units: mm                 # optional override for DXF $INSUNITS
mech:
  outline:   "OUTLINE|PCB"
  holes:     "HOLES?|MOUNT.*"
  fiducials: "FID.*"
  comp_3d:   "COMP_(?P<ref>.+)"          # named group 'ref' = refdes
  heatsink:  "HS_.*"
  keepout:   "KEEPOUT_H(?P<h>[0-9.]+)"   # named group 'h' = height limit (mm)
  chassis:   "CHASSIS.*"
  case:      "CASE.*"
ecad:
  ref_holes: npth                         # npth | all
  ref_hole_min_diameter: 1.5
registration:
  tol: 0.3                                # feature matching radius
  diameter_tol: 0.15
  mirror: auto                            # auto | true (bottom view) | false
  allow_scale: true                       # detect inch/mm/cm/m mix-ups
  use_outline_vertices: false             # add outline corners as reference points
  use_fiducials: true
  use_outline_icp: true
  anchors:                                # break symmetric patterns
    - { mech: [123.4, 56.7], board: [3.5, 3.5] }
checks:
  hole_position_tol: 0.1
  hole_diameter_tol: 0.1
  hole_search_radius: 2.0
  mech_hole_min_diameter: 1.0
  outline_tol: 0.2
  cutout_tol: 0.2
  component_position_tol: 0.5
  component_rotation_tol: 2.0             # degrees
  component_search_radius: 3.0
  case_height: 12                         # default ceiling (optional)
  min_clearance: 0.5
  registration_rms_max: 0.05
heatsinks:                                # first matching rule wins
  - { layers: "HS_U1", component: U1, resistance: 6.0 }       # K/W
  - { layers: "HS_.*", fins: { count: 8, height: 10, thickness: 1, length: 20 },
      h: 10, k: 200, ambient: 35 }
chassis: { temperature: 45, contact_resistance: 0.5 }          # or h_contact: W/m²K
case:    { temperature: 40, k_air: 0.0263 }
```

Drawing conventions: z = 0 is the board's top surface. Component bodies and heat sinks use elevation + thickness (2.5D) or 3D meshes (3DFACE / POLYFACE / MESH). Keepouts give their limit through the `h` group in the layer name, or through their own top `z`. A case item with elevation `g` > 0 is a lid at height `g`, which produces both a height ceiling and an air-gap boundary.

## Registration

1. Reference features: drawing circles on `holes` (and `fiducials`) against Excellon holes ≥ `ref_hole_min_diameter` (only non-plated ones when `ref_holes: npth`) and X2 `FiducialPad` flashes. Outline corners can be added.
2. RANSAC with 2-point hypotheses tests rotation, mirror, and (optionally) scale exhaustively for small hole counts. Umeyama/Kabsch then refines the best hypothesis, and outline ICP refines it further.
3. The report gives rotation, translation, mirror, scale, feature RMS, and outline RMS before/after ICP.
4. **Symmetric patterns.** If several transforms fit equally well (for example four holes in a rectangle), the result is NG with an "ambiguity" item. Add an asymmetric hole, use a distinct diameter, or set `registration.anchors`.
5. **Outline ICP** is kept only if it actually improves the outline fit without degrading the hole fit. A drawing outline that is wrong therefore shows up in the outline check and does not shift the transform.
6. **Unit errors.** With `allow_scale: true`, a drawing in inches labelled as mm is detected (scale 25.4) and reported as a warning. The checks still run in the corrected scale.

## DWG

pcbsim does not read DWG directly. It calls a converter and then reads the resulting DXF:

* [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter) (free): `ODAFileConverter` on `PATH` or `PCBSIM_ODA=/path/to/ODAFileConverter`
* [LibreDWG](https://www.gnu.org/software/libredwg/) `dwg2dxf`: on `PATH` or `PCBSIM_DWG2DXF=/path/to/dwg2dxf`

If neither is installed, the error message explains these options, plus exporting DXF from the CAD tool (FreeCAD: *File → Export → AutoDesk DXF*).

3DSOLID / BODY / REGION (ACIS) entities in a DXF are skipped with a warning. Export those parts as STEP and pass them with `--step`.

## Simulation link

Add this to a simulation config:

```yaml
mechanical:
  match: match.json        # relative to the config file
  offset: [0, 0]           # config origin − Gerber origin (mm)
  apply_boundaries: true
  require_ok: true
```

On `pcbsim run`:

* The derived boundaries (`hs_<ref>`, `chassis_<layer>`, `case_<layer>`, `hs_<layer>`) are appended to `thermal_boundaries`. A boundary of the same name, or an existing heat sink on the same component, in the config takes precedence.
* If the match is NG, the run stops with exit code 5 and lists the NG items. `--force` runs it anyway.

## Limitations

* IPC-2581 and ODB++ inputs are not implemented yet (public specs, planned).
* STEP support reads only part bounding boxes (via the optional cadquery dependency); exact 3D clearances are not computed.
* Component rotation from a box-shaped body is compared modulo 90°, and square or round bodies (aspect ≤ 1.05) are not rotation-checked at all, because their outline has no orientation.
* One drawing describes one board side: a mirrored (bottom-view) drawing is the bottom side. Height checks compare items only against ceilings on their own side. Pass two runs for a double-sided enclosure.
* STEP solids count as component bodies only when their product name matches `mech.comp_3d`. Unnamed `solid_<n>` parts (board, enclosure) are ignored for component checks.
* A failed `pcbsim match` deletes the previous JSON at the target path, so `pcbsim run` never trusts a stale result.
* The E2E tests use KiCad-8- and FreeCAD-format files generated by `tests/cad_fixtures.py`. KiCad and FreeCAD themselves are not run in CI.
